## 主な機能

- 無人島の通常採集ルート
- 収集リストを指定して必要数まで採集
- 選択した畑への水やり
- 牧場の餌やり・収穫
- 日本語UI
- アイルデジョンによる拠点帰還

## 必要なプラグイン

- vnavmesh
- Lifestream

機能によって使用します。

## コマンド

- `/explorersiceboxjp`
- `/iceboxjp`
- `/explorersiceboxjp s`
- `/explorersiceboxjp settings`

## 注意事項

- 本プラグインは **本家 Explorers-Icebox の公式リリースではありません**。
- 本家作者様への問い合わせではなく、本改変版に関する問題は本リポジトリ側で扱います。
- 飛行未開放など、キャラクター側の進行状況によって一部の採集ルートを利用できない場合があります。
- 畑の収穫・植え付け、マメットによる管理など、未対応の機能があります。
